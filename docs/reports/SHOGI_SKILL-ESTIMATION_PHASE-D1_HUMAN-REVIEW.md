## 4. Review所見

- 2級の一方がoverall 75.8476で、初段の複数局を上回る。単純thresholdは成立しない。
- 1級の範囲は63.7162〜80.4148、初段は63.3893〜90.3303で大きく重なる。
- opening単独はrank順序との対応が弱く、LOOU MAE 1.25。phase表示には独立した追加検証が必要。
- endgameはLOOU MAE 0.8125でも、eligible不足と同一player変動が大きい。見かけの精度だけで採用しない。
- 16 rowsの半分が同一playerであり、row-random splitなら深刻なリークになる。LOOU必須という判断を支持する。

Human Review判定は「pipeline検証資料として合格、production rank表示根拠として不合格」。D2のuser-balanced収集後に再レビューする。
