# Phase 1 UX Contract

After submit, the UI must not imply that analysis completion is required for the game record to exist.

Preferred wording concepts:
- `棋譜を保存しました。解析待ちです。`
- `解析中（棋譜は保存済み）`
- `解析に失敗しました。棋譜は保存されています。再解析できます。`
- `解析完了`

The exact Japanese wording can be refined, but the distinction between durable storage and analysis state must remain obvious on iPhone-sized screens.
