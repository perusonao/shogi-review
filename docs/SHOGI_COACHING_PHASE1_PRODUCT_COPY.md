# Phase 1 Product Copy

Prefer reassuring factual wording, not technical queue language.

Success: `棋譜を保存しました。解析を開始します。`
Waiting: `棋譜は保存済みです。解析を待っています。`
Failure: `解析に失敗しましたが、棋譜は保存されています。再解析できます。`
Storage failure: `棋譜を保存できませんでした。もう一度お試しください。`

Final wording may change after UI review while preserving these semantics.
